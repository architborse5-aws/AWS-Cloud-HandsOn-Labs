## 📂 Hands-On Labs

### 01. Amazon EC2
- Launch Ubuntu EC2 instances.
- Connect using SSH.
- Install and configure software.
- Manage Linux servers.

### 02. Amazon EBS
- Create and attach EBS volumes.
- Format storage using Linux.
- Mount additional storage.
- Configure persistent mounting.

### 03. Amazon S3
- Create S3 buckets.
- Upload and manage objects.
- Explore bucket permissions.
- Understand storage security.

### 04. AWS IAM
- Create IAM users and groups.
- Understand IAM policies.
- Explore roles and permissions.
- Apply least-privilege access.

### 05. Amazon VPC
- Understand VPC networking.
- Create public and private subnets.
- Configure route tables.
- Explore security groups.

### 06. AWS Lambda
- Create serverless functions.
- Configure event triggers.
- Explore automated workflows.
- Understand serverless architecture.

### 07. CloudWatch
- Explore EC2 monitoring.
- Understand metrics and logs.
- Configure monitoring alarms.
